# 640 × 480 横屏布局

设备与主机使用同一份 `aiglass_home.c`，默认尺寸为 640 × 480 横屏。
主机预览按帧缓冲比例等比显示，点击位置转换为帧缓冲坐标；设备 framebuffer 分辨率和输入旋转由宿主驱动配置。

| 区域 | 位置与尺寸（px） |
| --- | --- |
| 顶栏 | 高 40；时钟、页面标题、连接与电池状态 |
| 内容 | 左上角 (12, 52)，616 × 328 |
| 操作状态 | y=392，高 24；返回及操作结果 |
| 消息分隔线 | y=424 |
| 常驻消息 | (12, 430)，616 × 48；最多两行，超长内容省略 |
| 菜单 | 四列两行，单格 145 × 134，间距 12 |
| 全部应用 | 内容区 y=292，高 36 |
| 对话导航栏 | 宽 88，三行各高 101，间距 12 |
| 对话右栏 | 内容区 x=100，宽 516；文本区域高 190，可纵向滚动 |
| 手机消息正文 | 右栏 y=88，高 196，可纵向滚动 |
| 首次配对 | 两栏宽 302，间距 12；底部刷新/解除配对与进入应用按钮 |

文字使用内置 16 px 字体，行高 22 px，行间距 4 px。按钮文字居中；标题和文件名超长省略。
输入面板覆盖当前 view，编辑区和屏幕键盘按 480 px 高度分配。主机输入辅助仅填写当前 LVGL
编辑框，保存和发送仍经共用的 LVGL 事件处理。

服务保留最近一条手机消息的原文，界面在底部持续显示，切页后仍可见。
主机预览页在画面下方另外展示完整文字，保留换行，长内容可滚动；内容作为文本显示，不执行 HTML。

[layout.svg](layout.svg) 是由 [layout_preview.py](../tools/layout_preview.py) 生成的结构示意，
不是运行截图。实际页面图与 640 × 480 浏览器联调截图位于 `.host-debug/reports/`。
原生测试覆盖 16 个页面的重复切换，浏览器测试检查消息区与图片的相对位置。
显示驱动、触摸坐标和物理屏幕可读性属于板端验证范围。
